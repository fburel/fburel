## What I do
I'm a developer at heart. I love coding, solving problems and finding elegant
solutions — and I can't stand wasted time or repetitive tasks with no added value.
Since my first job in industrial software, my reflex has been the same: when
something makes me or my team lose time, I write the code that automates it.
AI is simply one more tool in that box.

## How I build
These days, AI coding agents write most of the code. I design the architecture,
write the specs (Markdown) and drive Claude Code and Lovable under strict rules:
design patterns, tests at every level, and a review of every delivery.
